🚀 Как задеплоить на Render с переменной GEMINI_API_KEY

Этот файл уже содержит специальный маркер __RENDER_GEMINI_API_KEY__, Выберите удобный способ деплоя на Render:

Способ 1 (Самый простой — Static Site с 1 файлом index.html в GitHub)
  1. Переименуйте этот файл в index.html и загрузите в ваш GitHub-репозиторий.
  2. В панели Render.com нажмите New + → Static Site и подключите репозиторий.
  3. Во вкладке Environment добавьте переменную:
    Key: GEMINI_API_KEY   |   Value: ваш_ключ_AIza...
  4. В поле Build Command укажите эту команду (она автоматически подставит ваш GEMINI_API_KEY из Environment прямо в HTML при сборке):
sed -i "s|__RENDER_GEMINI_API_KEY__|$GEMINI_API_KEY|g" index.html

Publish Directory укажите: . (точка)

Способ 2 (Или введите ключ прямо в интерфейсе)

Вы также можете в любой момент нажать кнопку «API & Настройки» в правом верхнем углу страницы и вставить ключ вручную — он сохранится в браузере (localStorage).
